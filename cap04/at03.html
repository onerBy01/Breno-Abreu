Seção 2 — Ranking de tecnologias

  1. JavaScript: A linguagem de programação que permite dar interatividade às páginas.

  2. CSS: Responsável por toda a identidade visual e layout do site.

  3. HTML: Responsável por toda a estrutura da página.

  4. Banco de Dados: Bases para salvar informações do sistema.

  5. HTTP: Protocolo baseado em requisição e resposta essencial para comunicação.

Seção 3 — Glossário de termos técnicos

HTML
Linguagem de marcação utilizada na construção de páginas Web.
CSS
Mecanismo para adicionar estilo e formatação a um documento Web.
JavaScript
Linguagem de programação interpretada estruturada, que permite implementar itens complexos em páginas web.
DOM
Document Object Model. Uma interface de programação para documentos HTML e XML que representa a estrutura da página.
API
Conjunto de rotinas e padrões estabelecidos por uma aplicação para que outras funções possam utilizar suas funcionalidades.
Mecanismo que permite que dois componentes de software se comuniquem entre si usando um conjunto de definições e protocolos.
HTTP
Protocolo de comunicação utilizado para transferir dados na World Wide Web.
Protocolo baseado em requisição e resposta operando na camada de aplicação do modelo TCP/IP.
URL
Endereço Web
Uniform Resource Locator. O link ou caminho definitivo utilizado para encontrar e acessar um recurso específico na internet.
DNS
Sistema de Nomes de Domínio
Domain Name System. Serviço responsável por traduzir nomes de domínios legíveis por humanos (como www.exemplo.com) em endereços IP legíveis por máquinas.
